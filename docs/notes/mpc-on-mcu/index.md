轮腿的 LQR 在大扰动下很容易让轮毂或关节电机的力矩打满。理想的做法是上 MPC，把力矩约束放进优化里，但 STM32 上在线求解二次规划（QP）并不现实。这篇记录我在单片机上部署的一种「离线 MPC」思路。

## 思路

模型直接沿用 LQR 的线性化模型。**模型是静态的，但规划是动态的**：每个控制周期都往前预测一次，再根据预测结果修正增益。

1. 预测步长取 N = 5：用模型推算未来 5 步的状态变量和对应的控制力矩。
2. 检查第 5 步是否超出力矩上限。超出的部分占比记为 α。
3. 用 (1 − α) 缩放当前 LQR 增益矩阵 K 的每个元素，得到 K′ = (1 − α)·K，用 K′ 输出这一拍的控制量。

示意伪代码：

```c
/* 每个控制周期执行一次 */
x_pred = x;
for (k = 0; k < N; k++) {          /* N = 5 */
    u_pred = -K * x_pred;
    x_pred = A * x_pred + B * u_pred;
}
alpha = max(0, (|u_pred| - tau_max) / |u_pred|);  /* 第 N 步的超限比例 */
u = -(1 - alpha) * K * x;
```

## 代价函数

这里的代价函数不考虑控制量本身的大小，只考虑控制误差，也就是预测值和实际值之间的误差。求代价函数最小值时直接令一阶导数为零，就能得到解析的最优解，不需要迭代求解器。

MPC 的输入是整套观测的状态变量，先预测，再让实际状态尽量贴近预测。

## 调参手感

主要调的是代价函数里输入序列的权重：

- **太大**：收敛慢，但姿态好看。
- **太小**：收敛快，但会「噼里啪啦」地抖着收回来。

在小轮方案里，这层预测对通过性的帮助很明显，机械选型上的讨论见 [RM 轮腿机械选型](../rm-wheel-leg-mechanics/index.md)。
