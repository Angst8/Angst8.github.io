步兵的云台姿态解算（BMI088 + EKF）和轮腿的打滑处理（简化卡尔曼融合速度）都用到了卡尔曼滤波。原理推导网上已经很多，这里只记调参时真正要想清楚的五个参数。

## 五个关键参数

| 参数 | 含义 |
| --- | --- |
| x₀ | 初始状态变量 |
| P₀ | x₀ 的协方差 |
| A | 状态转移矩阵 |
| Q | 过程激励噪声协方差 |
| R | 测量噪声协方差 |

### x₀：影响最小

可以直接把第一个测量值作为初始状态。

### P₀：只要不为 0

初始协方差的取值对滤波效果影响很小，都能很快收敛。

### A：取决于状态转移是否确定

- **确定且线性**：常用来估计运动方程已知的物体，比如匀速或匀加速直线运动，直接用标准卡尔曼。
- **确定但非线性**：不能直接套用。用雅可比矩阵把期望和方差线性化，就是扩展卡尔曼滤波（EKF）；为了避开泰勒展开的截断误差，引入 Unscented 变换，就是 UKF。
- **不确定**：常见于预测机动目标的轨迹。
  - 灰色卡尔曼：不依赖运动状态方程，用前几个时刻的估计值建立灰色微分方程，预测下一时刻。
  - 交互式多模型卡尔曼（IMM）：多个滤波器加权自适应，避免目标机动时滤波发散。

### Q：过程噪声

- 状态转移确定时，可以离线测试找到最优的 Q；Q 越小越好，增大 Q 会让收敛变慢、状态扰动变大。
- 状态转移不确定或随时间变化时，Q 不能取定值，而是随时间变化的 Q(k)，这就是自适应卡尔曼滤波。

### R：测量噪声

- R 是滤波器的输入，但很多时候拿不到准确值。
- R 过小或过大都会让效果变差：R 越小收敛越快，越大收敛越慢。
- 先用实验找到合适的 R，再用它做实际滤波。
